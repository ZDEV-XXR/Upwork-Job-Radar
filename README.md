# Upwork Job Radar 🚀

An automated job discovery tool built for freelancers to track high-value opportunities in real-time.

## 🛠️ Tech Stack
* **Framework:** Chrome Extension Manifest V3 (MV3)
* **Background Logic:** Service Workers & Alarms API
* **Data Scraper:** Vanilla JavaScript (DOM Parsing)
* **Storage:** Chrome Local Storage API
* **UI:** HTML5, CSS3, and Asynchronous JS

## ✨ Features
* **Keyword Matching:** Targeted tracking for roles like `Unreal Engine 5` and `C++ Programmer`.
* **Smart Notifications:** Real-time desktop alerts with direct links to Upwork posts.
* **Countdown Timer:** Integrated UI showing the exact time until the next automated scan.
* **ID Persistence:** Saves viewed job IDs to prevent duplicate alerts.

## 🚀 Installation for Testers
1. Download the `src` folder.
2. Go to `chrome://extensions`.
3. Enable **Developer Mode**.
4. Click **Load unpacked** and select the folder.
